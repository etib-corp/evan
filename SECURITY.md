# Security Policy

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability in
Evan, please report it privately before disclosing it publicly.

Please do **not** open a public issue for security vulnerabilities. Instead,
email the maintainers directly:

- Clément: <clement-antoine.xavier@epitech.eu>
- Léo: <leo.sautron@epitech.eu>
- Julien: <julien.ferdinand@epitech.eu>
- Nathan: <nathan.maillot@epitech.eu>

Include as much detail as possible:

- The affected version and platform.
- Steps to reproduce the issue.
- A description of the impact.
- Any suggested fix, if available.

## Response

We will acknowledge your report as soon as possible and work with you to
understand and resolve the issue. We aim to keep you informed of progress
throughout the process.

## Disclosure

We will coordinate disclosure of the vulnerability once a fix is available.
We ask that you refrain from public disclosure until we have had a reasonable
opportunity to address the issue.
